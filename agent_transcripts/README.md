# Agent Transcripts — The Lenny Growth Assistant

This folder contains curated records of the AI-assisted development sessions used to build this project. These logs document the key decisions, errors, corrections, and reasoning that shaped the final architecture.

Secrets and sensitive data (API keys, passwords, personal identifiers) have been removed before committing.

---

## Files in This Folder

| File | What it covers |
|---|---|
| `session_01_environment_setup.md` | Python environment conflicts, dependency resolution |
| `session_02_database_connection.md` | DNS/connection string bugs, Supabase migration |
| `session_03_rag_improvements.md` | Query rewriting, confidence threshold, hybrid search |
| `session_04_ui_redesign.md` | Claude-style UI implementation decisions |

---

## How to read these logs

Each log follows this format:

```
PROBLEM:   What the agent/developer was trying to do
ATTEMPT:   What was tried
ERROR:     What went wrong (exact error message)
DIAGNOSIS: Root cause analysis
FIX:       What change solved it
DECISION:  Design reasoning recorded in code comments
```
